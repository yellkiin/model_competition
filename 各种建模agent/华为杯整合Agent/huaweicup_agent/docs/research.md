## 2. 工作流与约束

总控从完整题面建立固定条件、决策变量与跨问依赖；调研记录来源与阅读范围；建模给出一条整体主线与有限候选；程序实现固定划分、种子和评价口径；绘图只读新鲜数据；论文最后写摘要；独立审稿和反例检验检查缺失条件与过强结论。

创新候选统一回答：基线哪里失效、为何失效、数学上改了什么、额外代价、什么实验能否定它、如何与已有方法比较。没有验证就称机制假设，不称“最优”“首次”或保证获奖。保留无提升和失败记录。

已实现的离线工具包括输入封存、来源卡、递归依赖过期检查、CSV 科学绘图、XeLaTeX 编译、数表同源输出、AI 记录和精确 PDF 字节冻结。`render` 只写合成演练，真实赛题正文由宿主写作；本次没有接入实际 LLM API 完成真实赛题端到端求解。
