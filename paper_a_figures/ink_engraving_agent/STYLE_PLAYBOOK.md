# 线刻设色 · 风格系统说明

这套风格不是只服务于总流程图，而是用于整篇论文图件的一致化母版。目标是：

- **保留黑白精细线刻的高级感**；
- **只在关键机制上使用低饱和点色**；
- **让流程图、数据图、机制小图共享同一视觉语法**；
- **保持可编辑**：SVG 中保留文字与对象，数据图保留原绘图代码与数据。

## 1. 角色槽位

固定三类角色槽位：

- `structure`：结构、状态、关键路径、主流程中的决策骨架
- `memory`：驻留、搬运、张量集合交易、容量/Spill相关
- `fifo`：FIFO 读窗口、缓存填充、读时序、Q3差异

如果后续别的图没有三种角色，也不要硬凑齐；只使用涉及到的槽位。

## 2. 配色主题

同一篇论文只固定**一套主题**。当前提供：

- `qinglu`：青绿·赭石（默认）
- `qianjiang`：浅绛·苔色
- `yanlan`：烟岚·石青
- `mono`：黑白灰

建议正文默认使用 `qinglu`。黑白打印或补充材料可切换 `mono`。

## 3. 线条层级

- 主流程箭头：2.8
- 反馈／条件通路：2.1
- 模块内部局部连线：1.8
- 一般轮廓：2.0
- 细排线：0.85

流程图要求：

1. 模块间**一条逻辑关系只保留一根主线**；
2. 反馈线走外侧；
3. 起终点落在明确端口上；
4. 公式、标题、说明块是避让区，连线不能压进去。

## 4. 数据图迁移规则

对折线、散点、柱图、热图：

- 不改变原始统计、坐标范围、误差带和归一化；
- 优先映射到 `structure` / `memory` / `fifo`；
- 颜色不足时用墨色、线型、标记扩展；
- 热图默认用单调 sequential；只有存在真实中心时才使用 diverging。

## 5. 可编辑交付

每张图至少保留：

- `.svg`（文字可编辑）
- `.pdf`（论文插图）
- `.png`（快速预览）
- 对应 `.py` 或原始绘图脚本

## 6. 推荐工作流

1. 先确定图的科学角色和对象；
2. 再选主题色（整篇保持一致）；
3. 流程图先整理连接结构，再加淡色承托；
4. 数据图先用 `mpl_context()` 包住原图，再按标签映射角色；
5. 导出 SVG/PDF/PNG 三份；
6. 检查论文缩放尺寸下是否仍清晰。
