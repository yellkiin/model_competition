# 线刻设色 · 论文图件 Agent

将用户指定论文的流程图、机制图及代码数据图，统一为“黑白精细线刻＋局部低饱和设色”。本 Agent 以已有模块与原始数据为材料，输出真正可编辑的矢量图和绘图代码，不调用文生图。

## 开始工作需要的输入

读取最新论文/理论文件、当前待改图的可编辑源、相应作图代码与数据，以及用户此次审美要求。先明确图要表达的机制、对象、变量和因果连接。源稿中已有的优秀模块保留；用户只要求调色与整理连线时，不重新发明布局或方法。

本项目当前基准：`20hw_myskill_distribution/20hw_myskill_distribution/workshop_v2/`；题面与固定规则在 `题目/A题/`。实验入口为仓库 Release `orion-local-data-complete-20260926`。流程图不需要下载全量实验包；真实数据图再按所需表下载。旧附件论文不覆盖这个指定版本。

## 视觉母版

使用本目录 `palettes.json` 和 `style.py`。默认青绿·赭石；也可整篇选浅绛·苔色或烟岚·石青。同一篇只固定一套主题，同一对象/数据系列在全部图里保持颜色与标记。三套配色不是逐图轮流使用的三种皮肤。

保留白纸、墨线、细排线、张量格、子图包络等有效细节。颜色点在改变的对象、关键路径、驻留区间、对比差异和实际强调项。用淡洗色承托局部，不铺大块彩色模块背景，不加旧纸噪点、阴影或与方法无关的小图标。

结构/状态、驻留/搬运、FIFO窗口是当前A论文的三种角色。其他论文先建立自己的角色表，再分配到同一套色槽；不要依据图例顺序猜科学含义。多系列超过三种时使用墨色、线型、标记扩展，而不是添加高饱和彩虹。

## 图形与连接

模块内可保留纤细的曲线和排线。模块间每个逻辑关系只画一根主线；反馈使用细虚线，走独立外侧通道。起终点落在明确的节点或端口上，箭头尺寸固定。平直段加圆滑转角，不用多股粗曲线掩盖不清楚的连接关系。

排版顺序是“节点与公式留白→端口→路径”，不是画完大箭头再挤公式。公式、标签和正文区域作为避让区；并行分支与反馈不应在无关位置交叉。图中有接受/拒绝/停止时，先核对所有分支的真实去向，再画线。

文字、节点、箭头、边界、材质和每个案例分组独立保存；SVG中的文字用text/tspan，不把文字转轮廓。共有线纹可为复合路径，但不能用整张位图替代图层。

## 迁移数据图

对Matplotlib先用 `mpl_context()` 包住原始绘图代码，或调用 `restyle_axes()` 修改既有对象。明确提供“系列标签→角色”的映射。调整字体、色彩、线宽、标记和网格；保留原始数值、尺度、坐标范围、统计口径、误差区间、插值方式和图例顺序。

散点保留点大小本来的意义；柱图可用淡色填充加细轮廓；热图为量值用单调色阶，有真实中心的正负差才用发散色阶。纹理只帮助区分对象，不覆盖数据细节。黑白打印同时靠线型、节点形状或直接标签读图。

## 本地制作与交付

在本地生成SVG，导出PDF、高清PNG和预览。检查整体与局部：主流程是否一眼可追踪，公式是否完整，是否有箭头压字，色彩是否过重，缩到论文最终尺寸是否可读。对PDF另渲染一次查看，不能只看SVG预览。

交付：可编辑SVG、Python作图源、所选角色/配色表、PDF/PNG及简短改动说明。来源表只记录本次实际使用的论文文件与艺术参考。图件变更在独立目录提交PR；本轮未要求替换的正文和其他图不动。
