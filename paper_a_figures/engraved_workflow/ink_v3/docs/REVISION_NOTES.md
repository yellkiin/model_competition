# 第三版修订与核验记录

## 修改范围

新版本独立放在 `paper_a_figures/engraved_workflow/ink_v3/`，不覆盖第二版，不改论文正文、求解器、数据或其他图件。依据用户给出的第二版截图以及 main 基线 `70d4888886cd9f77037f7b010ce0241349ef056d` 的指定来源制作；没有查询、读取或参考 PR #57。

## 保留

六算子—张量依赖示例；A/B/C/D 子图包络；核上排布及 B 迁移；基础构造、结构负载、驻留重组、FIFO 时序四类示意；处理器剖面、M/V/MTE2/MTE3、L1/UB、DDR、只读 L2；线刻排线、白底和灰阶层次。灰阶为主版，另附青绿设色备选。

## 调整

画布改为 420 × 262.5 mm，采用三个对齐的主模块和一个底部反馈带。主链统一从左向右，跨模块连接仅四条，箭头加粗并放大箭头头部。删除底部图例、字典序判断菱形、停止菱形、多条筛去/接受/停止分支，以及 Step1/2/3 和任务等待常数的密集文字。相关语义移至独立说明，而非从算法中删除。输出中的 Q3 同方案配对保留在搜索之外。

## 本轮实际检查

- 执行 `build.py --all-palettes`，生成两套 SVG、PDF、6000 像素 PNG 和 1800 像素预览。
- SVG 为原生矢量；文字保留 text/tspan；无嵌入位图，无随包字体文件，无网络依赖。
- 自动检查四条主连接、SVG ID 唯一性、已删除文字及必需对象。
- 使用 Inkscape 对 99 个文字对象查询边界：无文字越界，无文字对象互相重叠。
- PDF 为单页；通过 Inkscape 输出，并用 Poppler 重新渲染检查。另使用 MuPDF 核查页面及字体嵌入情况。
- 对主版与设色版进行视觉检查，重点检查六算子标签、核心排布、驻留窗口、主箭头、反馈与公式。

上述检查属于制图和导出检查，不是重新求解算例或复测算法性能。
