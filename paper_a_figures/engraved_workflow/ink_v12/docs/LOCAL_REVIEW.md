# 第十二版实际核验与审阅

## 范围和基线

基于 main 中已发布第十一版，八份输入 SVG 的 Git blob 均已锁定并在本地核对。只修改根视口、等比例物理尺寸及版本说明。原有各版本、PR #69 整篇论文、求解程序及实验数据没有修改。

## 实际完成

本地运行 `build.py`，四套配色均完成 SVG、SVGZ、矢量 PDF、高清 PNG、预览和两种 A4 纸面校样。恢复根属性及 title/desc 后，八份 SVG 的 XML 与 V11 完全一致；所有文字、图形、坐标、变换、配色、框线和连接均保留。可编辑 SVG 每色 107 个文本对象，便携 SVG 无活动文字。

Inkscape 检查五个可见内容层的包围框均处于新视口内；背景底板允许在视口外延伸。四份紧裁 PDF 均单页、无位图资源、无字体资源；SVGZ 解压内容与相应 SVG 完全一致。两类 A4 校样均核对纸张尺寸和至少 25 mm 页边距。输出尺寸与对象核验结果见 VERIFICATION.json。

已用 MuPDF 独立渲染四份紧裁 PDF，查看四色整图及同纸张尺度对照。未发现新增遮挡、断裂箭头、缺字或裁边。由于图内对象没有变化，统一的正比例缩放不改变任意两对象原有的相交关系。

## 放大口径

纵向 160 mm 版心仅因裁减外部空白放大 1.33%。横置图页使用 247 mm 版心，相对于第十一版在 160 mm 处插入，线性放大比例为 `(247/160)×(3500/3454)=1.5643095`。对照 PDF 将前后版本放在相同 297×210 mm 纸张上，避免用不同截图缩放冒充字号提升。

横向放大是版式选项，不是已经修改整篇论文，也不是承诺原图中所有小注释都达到常见正文或图注字号。正文配套段落和两个互斥 LaTeX 片段均已提供；本次没有重新编译整篇论文。
