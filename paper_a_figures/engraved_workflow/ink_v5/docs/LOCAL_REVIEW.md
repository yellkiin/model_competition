# 第五版本地审图

本轮先在原第四版8个SVG上校验Git blob哈希，再进行原生矢量编辑。已导出并查看青绿、浅绛、烟岚、灰阶四套整图；对PDF中的居中连接、COPY配对、结构候选小图分别放大审阅。迁移箭头初稿曾出现箭杆穿出尖端的细小突出，已通过箭杆止于三角形底部、显式端帽样式和独立标准箭头标记修正，随后重新导出全部四套。

四套图文、公式与几何一致，只替换既有配色。原有48组数学对象保持不变。每套编辑SVG有84个文字对象；转曲SVG无文字依赖；四份PDF均为单页，未含字体资源或位图对象。高清PNG为6000×2860，预览为1800×858。

局部图由PDF经Poppler独立渲染；另用MuPDF核对过PDF资源和局部形状。`verify.py`检查坐标、立方体视觉中心、箭头几何、四配色一致性、SVGZ解压一致性、源文件未改动及PDF资源；这些自动检查补充而不替代上述视觉审阅。

`REVIEWED_SVG_SHA256.json`记录本地最终审稿8个SVG的SHA-256，用于发布时逐文件比对。仓库发布只复现已审过的矢量修改及导出，不执行算法实验，不覆盖旧图或论文。字体文件不包含在交付中。
