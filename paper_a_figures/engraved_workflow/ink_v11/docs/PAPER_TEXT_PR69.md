# 第十一版流程图：PR #69 论文配套正文

## 可直接放入论文的一段正文

如图1.1所示，首先将子图划分、核心映射与核内顺序组成完整方案，再通过基础构造、迁移、交换、切分、数据驻留和FIFO复用时序调整生成候选，其中问题一使用（a）—（d），问题二扩展至（e），问题三扩展至（f），各操作并非串行步骤。候选经可行性与下界筛选后，在任务、存储、流水线及共享带宽约束下统一评价，按总体任务执行时间、总额外数据搬运量的优先顺序比较，保留更优可行方案，并依据收益与成本调整后续搜索机会。第三问的COPY_IN在发射时查询只读L2，命中时读取其驻留数据，未命中则读取DDR；读入完成后按容量及FIFO规则尝试填充，COPY_OUT仍写入DDR。上述过程循环至预算耗尽，输出当前最优可行方案，再固定第三问方案进行无L2与有L2的配对评价。
