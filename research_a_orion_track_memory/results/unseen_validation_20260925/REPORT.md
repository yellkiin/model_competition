# 未调参迁移验证：固定 Task/驻留规则

本目录是在 005/051/059/067/073/083/090/092 五核规则冻结后，选择未参与规则调参的 048/068/085/086（差图）和 036/084/097（好图保护）做的独立迁移验证。旧 day01 指标按用户要求直接信任，未复现旧方案；只运行新增候选并用未修改官方评估器验收。

## 固定规则

- `policy.py` 统一定义 `U/L <= 1.04` 的近界停止、官方 `(makespan, added_copy_bytes)` 比较和问题类型诊断。
- 阶段A只做 fixed-owner/parameter-capacity epochs、凸边界与驻留修复；阶段B只从阶段A incumbent 做 tensor endpoint affinity、合法局部 Task/顺序修复。
- 不按 case 编号分支；所有新方案只有官方 Makespan 改善才替换，平分才看搬运。
- Q3 最终方案做同方案 no-L2；不改 FIFO、Spill、图、张量、cycles 或配置。

## 文献与机制

- A39：把一个 Tensor 的生产者/消费者集合视为有向超边式关系，并在收缩/拆分时保持商图无环；对应本轮 fixed-owner consumer bands 与凸边界。
- A16 COSMA：采用 create/preserve/spill/retrieve 的张量状态视角解释驻留与额外片外访问；不移植其自由换入换出或地址变量。
- A17 SERENITY：采用合法拓扑顺序中的活跃集/局部顺序思想；不做 graph rewriting。
- A18 HMCOS：采用层级与峰值热点的局部拆解；不把论文单内存模型当作本题官方容量算法。

## 时间、失败与边界

`per_case.csv` 分开记录阶段A/阶段B候选数、官方评估耗时、候选生成、构造和端到端时间；`trajectory.csv` 保留真实前缀；`run_diagnostics.csv` 保留完成/停止/中断状态。部分容器外层 supervisor 在孩子已继续运行时触发超时，恢复记录明确标注，未把中断评估当成成绩。旧方案没有重评。

本轮说明规则能从原八图迁移到新的五核差图，并在小二核切片继续有效；仍不能据此宣称完整 1–5 核或全100图冷启动替代旧 ORION。下一步应固定同一规则补3/4核，再决定是否扩大。
