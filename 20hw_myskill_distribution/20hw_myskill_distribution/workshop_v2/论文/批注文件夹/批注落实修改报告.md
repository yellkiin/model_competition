## 方法、术语与来源核对

已按仓库真实位置阅读原题DOCX、理论绑定、算法说明、术语表、来源映射和实际方法；Windows绝对路径未作为读取入口。基本绑定在 `求解/论文理论/bindings/20260925T204725662983Z/`，执行核对使用 `求解/支撑材料源/方法源码/` 与 `提交附件/支撑材料文件/其他数据/官方评价代码/`。

| 术语/对象 | 定义及使用位置 | 核对结论 |
|---|---|---|
| 完整方案、商图和可行性 | eq:plan、eq:partition、eq:acyclic、eq:evaluator | 划分、归核、核序为决策；开始时刻与换出由执行器产生 |
| 正式目标、额外COPY | eq:makespan、eq:objective | 周期为主、周期相同再比较字节；未用通信代理替换 |
| 基础构造、上行优先级、EFT | eq:frontier_construct、eq:construct_map | 对应实际多粒度划分及归核估计，不冒称精确周期 |
| 结构候选、驻留候选 | eq:group_move、eq:release_split、eq:residency_hull | 各变换的修改集合、归核、顺序及数量边界明确 |
| 归属保持重组、分量分批 | eq:owner_bands、eq:batch_width | 深度层、跨核切换层与容量估计用途分别说明 |
| 全局下界、候选下界、质量界 | eq:lower、eq:taskbound、eq:gap | 全局界须对全部方案有效；筛选严格使用L(y)>当前周期 |
| 来源优先级与接受规则 | eq:sourcepriority、eq:accept、alg:joint | 近期八次反馈、真实成本、当前最好解收益及严格字典序匹配实现 |
| FIFO队列、服务池、命中字节率 | eq:q3_two_pools、eq:q3_hit | 发射查询、每次读完尝试填充、命中不刷新、不合并在途同张量读 |
| 纯顺序候选与驻留窗口 | eq:fifo_move、eq:fifo_priority、eq:cachewindow | 按真实未命中事件生成移动，不提交等待或预测保证 |
| 多尺度通信感知归核 | eq:q3_band_score | 层带内弱连通分量、0.7/0.3负载及λ通信权重、通信去重与FIFO代理 |
