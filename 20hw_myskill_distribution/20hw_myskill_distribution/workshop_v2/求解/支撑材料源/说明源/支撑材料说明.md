# 支撑材料说明

本材料对应通用神经网络处理器下的多核调度问题，共三问。

| 文件夹名称 | 主要内容 |
|---|---|
| 问题一 | 完整方法源码、代码环境说明和 Task/调度逐例结果表。 |
| 问题二 | 完整方法源码、代码环境说明和跨核交接/DDR 逐例结果表。 |
| 问题三 | 完整方法源码、代码环境说明和 L2/FIFO 同方案配对逐例结果表。 |
| 其他数据 | 100 个原始计算图、官方配置、完整官方评价代码及来源说明。 |
| 其他支撑材料 | 1400 个已选主配置和 500 个同方案配对的计划/官方响应、各分片执行源码、数据表及整理复现程序。 |

## 整体复现顺序

使用 Python 3.10 及以上版本。从本说明所在的提交附件目录执行：

```text
python 支撑材料文件/其他支撑材料/复现程序/reproduce.py --output 复现输出
```

整理程序从 `其他支撑材料/已选评价/selected_index.csv` 找到每项已选计划与官方响应，读取响应重算逐例指标、同方案配对、均值及 SVG 图，并与附带主表的关键整数逐项比较。它不运行百图搜索。

## 数据与最终结果

原始 100 图、config.txt 和官方评价源码位于 `支撑材料文件/其他数据/`。最终的逐例主表、配对表和聚合表位于 `支撑材料文件/其他支撑材料/数据表/`；完整已选计划与官方响应位于 `已选评价/`，三个分片的实际执行源码快照位于 `实际执行源码/`。三个逐问中间图表为按问题展开的逐例长表。官方评价的时间单位为周期；原实验涉及不同分片与主机，本包按统一评价规则汇总结果，不对物理运行环境作单机断言。
