# 后续论文图件维护Agent

先读`../../论文/批注文件夹/批注1-3统一复核/论文修改总约束与批注原话.md`，再读本目录README及当前TeX图号/标签，读取图真正引用的数据表。以当前V7总图的白底、墨线、青绿/赭石/淡朱点色为母版，不改该总图原工作区。

每图先写清读者应看懂的一件事，再选表达：分布用真实逐点或阶梯累计线，配对保留对应关系，有限参数网格显示真实格点，流程在对象上显示具体动作。图形承担解释，正文说明必要定义、范围和结论；不重复长标题或把章节正文放进图里。

方法图保持对象身份与箭头端口一致，按网格布置；同向箭头对齐，直线/折线优先，小空隙不强塞弯曲箭头。多个候选必须先汇入检查再进入评价，不因视觉布置跳过算法步骤。机制示意不能画成实际实验时间线。

数据图调用本目录style；整篇固定一个主题，已有核心数、方法与基准的线型保持相同。保留全部有效案例、负值、零值、单位、配对含义及原统计口径。需要改变图型时先导出plot_data并同步修改准确图号的段落和图注；删除仅限信息重复或无助解释的图，不为突出优势隐藏相关负结果。

修改后从源码生成PDF/SVG/PNG；打开图和编译论文中的实际页面，检查刻度符号、最小字号、标签、公式、图号、引用与邻近文字。仅改图件/相关文字，不重跑实验，不改输入数据。图件源、修改说明和成稿一同提交独立PR，不自动合并，不附带字体文件。
