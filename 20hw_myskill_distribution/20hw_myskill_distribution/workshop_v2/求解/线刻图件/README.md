# 论文图件：青绿线刻设色统一版

正文共20幅图。图1.1采用用户指定的V13青绿母版，中栏两列三排展示六类候选，保留三环节与评价反馈回路。其余19图沿用#69的数据与入口，并按批注1—3统一复核。原始数据和求解器不变。

后续修改首先阅读`../../论文/批注文件夹/批注1-3统一复核/论文修改总约束与批注原话.md`。图号及源码对应见`FIGURE_EDIT_MAP.json`。

## 复现与编辑

在仓库根运行：

```powershell
python "20hw_myskill_distribution/20hw_myskill_distribution/workshop_v2/求解/线刻图件/build.py" --theme qinglu
```

Python需要Matplotlib和NumPy。机制图优先使用PATH中的Inkscape导出；没有Inkscape时，使用Node.js、Playwright与本机Edge/Chromium，由`render_svg.mjs`将SVG直接打印为矢量PDF，并生成PNG预览。可通过`PAPER_BROWSER`和`PAPER_NODE_MODULES`指定已有运行时。绘图不调用求解器。

图1.1采用用户提供的V13青绿图。便携源为`../../论文/图片/workflow_qinglu_v13.svg`，文字可编辑源为`../../论文/图片/workflow_qinglu_v13_editable.svg`，对应母版位于仓库`paper_a_figures/engraved_workflow/ink_v13/assets`。便携源文字已转为矢量轮廓，编辑文字时使用editable文件。导出论文副本：

```powershell
node render_svg.mjs ../../论文/图片/workflow_qinglu_v13.svg
```

机制图保留文字、矩形、连线、纹理及公式的`data-tex`，结果图保留SVG文字与坐标对象；正式PDF均为矢量导出。每幅图同时保存PDF、SVG和PNG。修改文本时直接改生成器或总图SVG，再导出，不能仅修改预览图。

## 样式及图义

全篇采用`qinglu`：墨线`#202724`，结构青绿`#446E67`，存储赭石`#94784D`，FIFO淡朱`#9A655B`。另外三种既有主题仍可切换，系列角色和线型保持一致。字体为本机合法SimSun、Times New Roman与数学字体，不分发字体文件。结果图小字说明统一左下角。

- 图4.1显示基础构造、迁移、交换、切分及统一执行；图4.2箭头绕开COPY标签。
- 图4.5保留每30秒已有解达成曲线：已获可用解、距记录终值不超过5%、达到终值；终值是本次记录末值。
- 图5.1以核心级任务、驻留改进与完整评价展开；图5.2横向展示L1/UB中同核复用及跨核DDR读写。
- 图5.5保留100个算例，零线虚线，负/正额外COPY变化分别用青绿/赭石，MB=10^6字节。
- 图6.1的共同操作a—e与FIFO操作f汇入同一候选评价；图6.2明确发射查询、完成填充及队首淘汰。
- 图6.3无L2黑色数值在线下，有L2数值在线上，以留白避线。
- 图6.4各核数分别将100图按时间缩短百分比排序；图6.5绘命中率与时间缩短百分比，保留100点。百分比由`100*(1-有L2周期/无L2周期)`得出，原周期比继续保存在绘图表中。
- 图6.6格内数字为千周期，颜色为相对各图默认配置的时间变化，0%为相同，负值更短，正值更长；黑框为1 MiB、250 B/周期。仅显示54个已评价格点。
- 图6.7保持两张量同一0—12000周期轴，另展示起始1400周期的五核读入。

`plot_data/`保存实际用于绘图的值，`RESULT_FIGURES.json`指向输入与输出。第一、二问使用`规范化数据/combined`，第三问正式结果使用绑定的500行表，参数与轨迹使用原研究表。

## 本轮续修

图4.1、5.1、6.1统一使用“联合方案—候选改进—执行评价”三个环节。第三问的共同操作与FIFO顺序操作在候选环节并列汇入检查，单一外侧反馈线返回当前完整方案。图4.1删除脱离图形对象的约束词语。图6.2填充连线改为直线。普通图注中的分号改为逗号或句号，结果数值和线型含义保持不变。
