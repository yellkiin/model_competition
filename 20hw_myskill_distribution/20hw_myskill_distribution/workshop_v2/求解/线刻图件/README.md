# 论文图件：线刻设色统一版

对应正文20个图号：图1.1直接采用PR #68已完成的V5青绿稿，其余19图重新绘制。所有数据来自现稿绑定表，不调用求解器。图1.1的原创母版继续由`paper_a_figures/engraved_workflow/ink_v5`维护，这里只在论文图片目录保留其已完成文件。

## 复现与编辑

在仓库根运行：

```powershell
python "20hw_myskill_distribution/20hw_myskill_distribution/workshop_v2/求解/线刻图件/build.py" --theme qinglu
```

Python依赖：Matplotlib、NumPy。机制图导出需要Inkscape在PATH中。数据图保留SVG文本；机制图保留文字、分组与矢量对象，公式保留`data-tex`及生成源码。每张输出PDF、SVG、PNG到原来`求解/问题一|二|三/图片/`路径，正文直接引用PDF。图1.1另有可编辑文字版及转曲版。

推荐整篇固定`qinglu`；`qianjiang / yanlan / mono`用于全篇主题切换，不能逐图随机换系列角色。主题来自仓库已有`paper_a_figures/ink_engraving_agent/palettes.json`。字体优先当前机器的Times New Roman与SimSun，数学使用Computer Modern；无原字体时显式采用本机可用衬线CJK字体。项目不分发字体文件。`PAPER_INK_FONT_DIR`可指向用户本机合法字体目录。

原`求解/draw_results.py`、`draw_overviews.py`、`draw_trace.py`已转接到本套绘图入口，避免未来运行旧入口还原旧风格。数据源、数据清洗及求解代码不变。

## 数据与布局

`plot_data/`保存每幅结果图实际用到的数值；`RESULT_FIGURES.json`指向输入与输出文件。第一、二问来自`规范化数据/combined`，第三问正式主结果来自当前论文已绑定的500行表；固定方案参数研究及执行轨迹仍使用原研究表。正文统一表述为正式结果、固定方案研究和记录时间，不将不同统计量混为同一收益。

线型、点形和低饱和设色共同区分系列；坐标、数据点和细网格保持清晰，线刻只用于机制对象、驻留区和局部材质，不遮蔽统计信息。
