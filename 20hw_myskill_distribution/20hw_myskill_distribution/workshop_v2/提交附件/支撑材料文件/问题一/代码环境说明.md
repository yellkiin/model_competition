# 问题一代码环境说明

## 环境与安装

原实验源码使用 Python 3.12；本包的响应重算程序只依赖 Python 3.10 及以上的标准库，无需安装第三方包。原官方评价源码与配置位于 `../../其他数据/`，完整方法源码位于本目录 `源码/research_a_orion_trident/`。

## 输入与依赖

输入为 `../../其他数据/官方输入/` 中的 100 个原图和 `config.txt`。本问研究 Task 分组、单核对照与多核调度；完整方法源码含公共模块与 vendor 依赖。选定计划与对应官方评价响应位于 `../../其他支撑材料/已选评价/`，逐项路径见 `selected_index.csv`。原实验搜索有运行预算和候选状态；本包默认不重新运行百图搜索。

## 运行方法

从提交附件目录执行：`python 支撑材料文件/其他支撑材料/复现程序/reproduce.py --output 复现输出`。该命令读取实际官方响应，重算逐例指标、聚合表和一张 SVG 图。原方法求解主入口为 `源码/research_a_orion_trident/solve.py`，需原实验 request 与运行环境；本包提供已选完整计划供审核，不将整理命令冒充重新求解。

## 输出与中间图表

本问较长逐例结果在 `中间图表/逐例结果_问题1.csv`；复现输出 `recomputed_main.csv`、`recomputed_pairs.csv`、`recomputed_means.csv`、`mean_speedup.svg` 与 `reproduction_report.json`。重算基于全部已选官方响应。

## 使用边界

计量单位为官方评价周期；性能比以每图单核原整图结果为分母。不同分片来自实际多主机记录，本说明不归并为单台机器。随机种子和本地预算属于原求解记录，整理命令不使用随机数。
