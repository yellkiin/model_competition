# 使用说明与限制

- `template_id` 固定为 `innovation-chain-5stage`，通过 `scripts/innovation_chain_5stage.py` 调用。
- `example.json`、`example.drawio`、`preview.png` 和 `example.pdf` 是该独立模板的可替换示例与导出证据；字段容量和阶段语义以 `references/innovation-chain-5stage.md` 为准。
- 模板已同步到 `.agents` 与 `.claude` 两端。示例内容只用于验证布局，使用到具体论文时必须替换为真实题意、数据和结果，并重新运行 strict、视觉和 PDF 入文审核。
