# 审计运行时只读缓存

正式工作流仍由共享 `workshop.py run` 和 `workshop.py finish` 调用原审计器。本目录只在环境变量 `HUAWEI_AUDIT_CACHE=1` 时启用进程内记忆化：首次调用完整执行共享图库目录、目录同步、图型预检和资源依赖扫描；同一审计子进程内相同参数的重复调用复用首次结果。它不保存跨进程结果，不更改图件、审计准则或返回结构。工作流包装器在运行前后继续核验共享资源和原始输入的一致性。共享模板在本次求解中保持只读。

原因：候选图和支撑材料的正式审计会对同一只读图库连续重复扫描；未缓存时单次审计约需五十分钟，超过 `workshop.py finish` 对单项审计的三十分钟超时限制。启用此缓存后仍由正式审计器重新计算每个子进程的首轮全量索引，并保留完整审计报告。
