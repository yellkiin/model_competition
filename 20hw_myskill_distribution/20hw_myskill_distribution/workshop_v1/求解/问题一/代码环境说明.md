# 问题一代码环境说明

## 环境与安装

正式运行环境使用 Python 3.13.15。独立重放与验证仅使用 Python 标准库；若继续运行绘图及论文构建，可在源码目录按 `python -m pip install -r requirements.txt` 安装随附依赖，锁定版本见 `requirements.lock.txt`。随机种子不适用：当前候选划分、排序和成对统计均为确定性过程。无需 GPU；具体运行时间依图规模而变，未设未经测量的硬件下限。

## 输入与依赖

题目原始100图和固定配置保留在 `../../其他数据/官方输入.zip`；2005份正式候选评估收据、原始响应与方案保留在 `../../其他支撑材料/正式候选评估.zip`。脚本会在本问 `源码/` 下解包并重建原始目录结构。问题一与前问的科学关系见正文；复现入口自身会对三问完整候选重新选择和独立核验。

## 运行方法

工作目录是 `支撑材料文件/问题一/源码/`。按顺序运行：python 问题一.py solve；python 问题一.py validate。首次运行前，`源码/求解/正式实验/总体摘要.json` 不应存在；在新目录复制提交包后运行即可。若需重新运行，另取一份干净的提交包副本。

## 输出与中间图表

`源码/求解/正式实验/总体摘要.json` 给出三问一至五核的100例正式汇总；`源码/求解/问题一|二|三/结果/逐例官方评估.csv` 与验证JSON记录逐例选择和时间线核验；`源码/求解/正式实验/逐问核验摘要.json` 给出各问所选五百组方案的核验统计。`中间图表/` 收录正文未完整列出的本问候选比较表。

## 使用限制

此入口从封存的正式官方响应重放全部候选的择优和独立时间线核验，并逐份检查响应摘要；它不重新运行全部耗时的官方事件模拟。需要从原始图再次执行完整评估时，使用随附的 `求解/run_official_experiments.py`、候选生成源码和题目未改动的评估源码。非官方L2网格不能计入题定默认配置成绩。
