# 三问正式结果图的科学问题与数据接口

本矩阵是绘图前的科学选题，所有数值必须取自完整的 100 例正式汇总及独立验证结果。每图形成唯一结论；具体来源模板、五项映射、三维取舍、质量证据与去向须在视觉计划和候选清单逐图登记。此前冒烟结果不得进入任何图。

| 编号 | 科学问题 | 预定数据字段及样本单位 | 优先表达及避免重复的理由 |
|---|---|---|---|
| q1-F01 | 输入图规模与连通结构的异质性有多大？ | 数据审计.csv；每图一例，`internal_ops/components/largest_component` | 规模与最大连通块占比的联合分布；这解释切图适用域而非重复成绩。 |
| q1-F02 | 2–5核平均加速及离散范围如何？ | 逐例官方评估.csv；每核100例的逐例`speedup` | 分位区间点图，标出1倍基线与均值。 |
| q1-F03 | 五核下不同结构的失速例在哪里？ | 逐例分析.csv；每图一例，`largest_component_fraction/q1_speedup` | 按结构分组的散点与失速阈值；不与核数汇总重复。 |
| q1-F04 | 加速和新增DDR搬运在逐例上如何权衡？ | 逐例分析.csv；每图一例，`q1_added_copy_bytes/q1_speedup` | 对数横轴的二维分布和非支配点；若第三轴是规模，比较三维候选的遮挡与尺度。 |
| q1-F05 | 哪些图结构触发依赖段候选胜出？ | 候选评估收据、数据审计.csv；每例每核一个候选胜者 | 结构分箱胜者矩阵；必须显示每格案例数，避免把缺样本误作规律。 |
| q1-F06 | 官方评估的计算成本与优化收益是否冲突？ | 所有候选评估收据；每候选、每配置的`makespan/elapsed_seconds` | 前沿图并标出分批候选的适用路由；这里的运行秒数仅为评估器耗时，不冒称方案生成耗时。 |
| q2-F01 | 在同一方案上，仅改变场景A/B规则带来多少收益？ | 场景配对分析.csv；每例每核的`scene_b_gain_same_plan` | 核数分组的分布比较，保留1倍线；与策略改选分开。 |
| q2-F02 | 场景B重新选择方案又带来多少附加收益？ | 场景配对分析.csv；每例每核的`q2_policy_gain` | 成对核数趋势与区间；不把场景本身效应归于算法。 |
| q2-F03 | 搬运增量由切图还是容量Spill驱动？ | 逐例官方评估.csv；每例每核`partition_added_copy_bytes/spill_added_copy_bytes` | 堆叠结构组成并注明字节；不得将负的净增量裁为零。 |
| q2-F04 | 场景B增益是否集中于某类图拓扑？ | 场景配对分析.csv＋数据审计.csv；每例每核 | 结构分层的增益点区间图，报告各层样本数。 |
| q2-F05 | 总时长降低时，新增DDR搬运是否也减少？ | 问题一/二逐例官方评估.csv；同例同核成对 | 双指标象限图；只比较同样例同核，不把不同方案的结果称为同方案因果效应。 |
| q3-F01 | L2在官方固定配置下的同方案收益分布如何？ | 问题三逐例官方评估.csv；每例每核`cache_gain` | 五核分布、1倍线及不获益比例。 |
| q3-F02 | 字节命中率和同方案收益的关系是否单调？ | 逐例分析.csv；每例每核`q3_cache_hit_rate/q3_cache_gain` | 散点、零命中标识及规模分层；不把相关称因果。 |
| q3-F03 | 容量与L2读带宽的真实响应面是什么？ | 非官方L2参数敏感性/逐配置最优.csv；每例3×3原始评估网格 | 可用真实三维响应面并以二维投影辅助；六例只作机制案例，不推广总体平均。 |
| q3-F04 | 容量扩展是否改变命中字节率，且各案例响应是否一致？ | 非官方L2参数敏感性/逐配置最优.csv；每例每格`hit_rate` | 案例分面的容量—命中响应，带宽仅作并列条件；六例只作机制案例。候选切换另以表格报告，若全无切换不为凑图绘制恒定矩阵。 |
| q3-F05 | Cache命中字节与失配字节如何随核数改变？ | 问题三逐例官方评估.csv；每例每核`cache_hit_bytes/cache_miss_bytes` | 按核数的成对单位量图，同时列命中率，避免把访问次数与字节率混用。 |

前三问共16张独立科学图，另需每问一张主要综合图、第一章路线图和至少一张额外有流程语义的正文图。正式选型要逐图比较 academic 与 modelviz 同类候选，全文同一 chart family 超过两张须具体重新比较并登记例外；真实三维机会应逐图审阅。图形个数本身不授予任何科学或视觉门禁通过状态。
