# A题求解计划与验证协议

本次运行：`workshop_v1`，正式输入为题目 DOCX、官方 A 题附件 100 个 JSON 和固定 `config.txt`。环境冒烟记录不计入成绩。原图审计结果见 `求解/数据审计.json`／`.csv`；正式候选评估写入 `求解/正式实验/`，探索输出保留于 `求解/探索/`。

## 数据审计结论

100 个连续编号的 JSON 合计 252791457 字节。每例均包含且仅包含 `ops`、`tensors`、`edges`，节点 ID 唯一、边只跨 Op/Tensor、无重复边、Op 依赖无环，数值非负且 Pipe／位置属于官方枚举。每图 766～38666 个 Op，其中 552～35705 个为须分配子图的非 COPY Op；最大单个张量 294912 字节。完整逐图规模、分支宽度、连通块数和操作类型保存在机器审计结果。数据是结构化优化实例，没有标签列、缺失值填补、时间切分或监督训练／测试泄漏问题。

## 共用计算与候选

采用官方 `_build_op_adjacency` 与 `_contract_excluded_copy_nodes` 得到非 COPY Op 的依赖 DAG。候选一把其无向连通块按 Op 周期工作量做确定性最大优先装箱，归于同一核心的块合为一个子图，减少场景 A 的 Task 切换。候选二按 DAG 最长路径深度划分依赖段，每段内连通块均衡分核；同段不同块互无依赖，跨段只允许前向依赖，故收缩后的子图图仍为 DAG。独立验证先用官方 `validate_multicore_plan`，再以三题官方评估器确证全局执行图可运行。

正式评估运行中观察到官方场景 A 对超宽图的单个巨型 Task 存在很高的调度计算代价。为满足题目要求的合理生成时间，加入事先固定的规模路由：当非 COPY Op 数除以核数超过 2500、且最大弱连通块不超过 600 个 Op 时，候选三把同核互相独立的连通块按最多约 800 个 Op 分批组成多个顺序 Task；该路由替代该配置下的巨型单子图候选，保留此前已经完成的官方评估供比较。若存在大连通块，则仍用依赖段候选与原连通块候选；小图沿用原候选。分批后的子图依赖无环，由官方校验器和评估器验证。该规则基于输入图规模而非测试输出分数，不改官方评估代码、固定配置或已完成收据；场景 B 合并同核 Task，分批顺序仍可能影响核内调度，因此三问分别重评。

模型选择为确定性组合优化。依据模型选择协议登记 C 类：没有需拟合的独立标签，官方仿真可直接评价候选；轻量深度学习 Pilot 无适当训练目标与验证样本，不运行伪监督实验。每个问题均保留单核／连通块基线、依赖段候选及失败收据；只有实测显示收益才选用复杂候选。

每个算例和核数独立生成候选计划并调用未修改的官方评估函数，计量运行秒数。正式候选计划、原始官方结果（gzip JSON）、摘要、输入及代码哈希逐一保存，断点续跑只复用指纹一致且通过的结果。选择标准优先最小 Makespan，接近时比较新增搬运与生成成本。问题三的无 L2 与有 L2 必须对**同一方案**评估；可分别优化用于有 L2 的方案，并报告与无 L2 最优方案的差异。

## 逐问工作

1. 问题一：100 图各运行官方整图单核基准及 2～5 核场景 A，输出逐例 Makespan／新增搬运和平均加速比。独立复算 `makespan=max(时间线结束时刻)`、核心数、调度节点覆盖、容量峰值、复制字节分解，核对官方结果。
2. 问题二：相同实例与核数在场景 B 下评估；记录同核复用减少的搬运、跨核搬运和 Spill，比较问题一。验证每核 L1／UB 峰值不超过配置，抽取跨核通信等待与结果一致。
3. 问题三：对相同方案分别运行无 L2 与 FIFO 只读 Cache，逐例记录 Makespan、搬运量、Cache 访问／命中次数和字节命中率；做容量、带宽参数敏感性实验时必须复制配置到工作区并明显标注为非官方主评估。独立复算命中字节比例和相同方案加速比。

## 科学验证与边界

主指标为每例官方 Makespan（越小越好）；次指标为新增 DDR 搬运字节及 Cache 命中字节率。1～5 核均值先逐例算比值再在 100 图上求平均，并同时报告分位数，以免大算例绝对周期主导。为了检验结果不依赖个别算例，还按规模、连通块数、DAG 宽度和 DDR 搬运占比做分层比较。评估器为题面规定的确定性模型；无法从同一程序输出获得独立芯片真值，因而验证只称约束／口径复核，不称真实硬件误差。

正式绘图前按绘图规范建立视觉计划，完成 academic 与 modelviz 双来源预检和真实结果字段映射。每问保留 4～6 张独立科学图及额外主要综合图；正文图数、候选图库、论文、附件及最终门禁按共享规范逐步执行。不得把探索试运行直接晋升为正式实验。
