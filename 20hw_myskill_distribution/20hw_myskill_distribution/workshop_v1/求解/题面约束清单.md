# A题题面约束清单

依据：`题目/通用神经网络处理器下的多核调度问题.docx` 全文（含公式和四幅图）；`数据/原始/A题官方附件/README.md`、`data/config.txt`、`docs/核内调度算法.md`、`docs/多核并行模拟执行算法.md`及官方评估代码。以下是题定事实与交付要求，方法选择另见求解计划。

## 共用问题定义

- 输入为有向无环 Op–Tensor 二部图，含 `ops`、`tensors`、`edges`。节点 ID 全局唯一，张量位置为 DDR、L1 或 UB；Op 有 `op`、`pipe`、`cycles`。四条 Pipe 分别为 MTE2、MTE3、M、V。
- 输出方案 JSON 顶层恰含 `node_to_subgraph` 和 `core_schedules`。前者必须覆盖全部非 `COPY_IN`／`COPY_OUT` Op，各值为非负整数 sgid；后者外层长度为核心数，各 sgid 恰出现一次，同核顺序和收缩后的子图依赖均须合法。
- 子图数量不限。目标首先是最小化官方评估器给出的全局 Makespan（周期），兼顾相对于原图的新增 DDR 搬运量。所有问题均要求算法随核心数变化稳定且高效。
- 所有正式算例为 `case_001.json` 至 `case_100.json`，配置只能使用官方 `data/config.txt`。L1=524288 字节、UB=131072 字节、DDR 总带宽=60 字节／周期。DDR 读写及换入换出共享此带宽。
- 核内三步由官方代码确定：拓扑访问序、容量不足时插入 Spill、四 Pipe 排布。多核模拟重新按共享资源计算 Makespan。不得把 Step3 局部时间当作全局时间。

## 问题一：场景 A

- 每个子图即一个 Task；跨子图数据经 DDR 中转，同核 Task 切换也清空私有缓存。跨核前驱等待 1000 周期，同核 Task 切换等待 100 周期。
- 为每个非 COPY Op 分配子图并给出各核心的子图执行顺序，重点缩短 Makespan、兼顾新增 DDR 搬运，在 2～5 核均生成有效结果。
- **正文**：给出 1～5 核平均加速比折线图。1 核加速比定义为 1；k 核加速比为官方单核整图 Makespan／场景 A k 核 Makespan。
- **附录**：100 个算例逐例列出官方 Makespan、新增 DDR 搬运量。**附件**：可复现 Python 程序和方案文件。

## 问题二：场景 B

- 每核全部子图合并为一个 Task，同核子图间可复用 L1／UB；仅跨核依赖经 DDR 搬运。跨核 COPY 的同步延迟为 500 周期。必须满足私有缓存容量。
- 在问题一基础上改进切图与调度，减少 Makespan 和额外搬运，在 2～5 核稳定生成有效结果。
- **正文**：给出场景 B 的 1～5 核平均加速比折线图，单核基准与问题一相同。**附录／附件**：逐例官方 Makespan 和新增 DDR 搬运量、可复现程序。

## 问题三：共享只读 L2 Cache

- 以场景 B 为基础，增加所有核共享、容量 1048576 字节、读带宽 250 字节／周期的只读 FIFO Cache；Cache 带宽与 DDR 带宽独立。只有 COPY_IN 查询 Cache，命中不刷新 FIFO 顺序。
- 研究 Cache 容量与带宽对切图、调度的影响，设计适配算法。固定官方参数用于主评估；容量／带宽敏感性只能作为另行登记的分析，不能冒充固定参数正式成绩。
- **正文**：1～5 核无 L2 与只读 Cache 的比较曲线；同核数 Cache 加速比为**同一方案**无 L2 Makespan／有 L2 Makespan。**附录**：逐例两配置 Makespan、新增搬运量、Cache 命中率。

## 输入与评估边界

- 官方示例生成器只演示合法格式，随机方案不作为性能基线。正式结果仅来自官方评估函数和固定配置；输入图及配置保持只读。
- 用例没有外部标签或训练集划分。此题是确定性图划分与调度优化，适用性判定为 C：不存在须拟合的独立预测标签，直接调用官方模拟器评价候选更可解释且可复核。任何后续学习型代理都须另行登记数据划分与训练预算。
- 官方结果为确定性仿真输出，不代表真实芯片实测能耗或运行时间。能效只能讨论机制，不能编造实测指标。
