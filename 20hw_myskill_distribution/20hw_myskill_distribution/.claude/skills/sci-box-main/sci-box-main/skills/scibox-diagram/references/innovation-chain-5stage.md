# 创新产业链五阶段研究框架图

`template_id`: `innovation-chain-5stage`。来源ref-21（ref-27为重复截图）。示例是参考图内容转录，用于演示模板，不是当前赛题的数据或科学结论。

## 适用范围与语义

适合同时展示五阶段研究安排、阶段内并列研究内容和右侧方法清单。左侧严格五个阶段，右侧四组方法对应研究范围，第三方法组覆盖机理与路径设计。内部三柱是创新趋势—创新力测度—国际比较的推进关系；结构与风险双栏各自扇入，不能改成跨栏比较；机理区两侧分别进入中心三链，中心再输出影响机理；重构区左侧三要素进入右侧2×3路径，末带为三节点政策链。

这些是该参考图的关系约束，使用时必须核对真实题意与方法，不能为了套图保留不存在的算法。若真实问题数量或依赖关系不同，选择其他模板或重新布局。

本模板与framework-3col同属研究框架族，但原图五个左侧阶段、嵌套容器、配色、短旗标与内部几何独立保存；既有模板未逐项复刻本参考设计，故保留独立ID。

## 输入与容量

JSON顶层仅允许template_id和texts。texts按下表提供所有字段；每项接受非空字符串或字符串数组，换行用JSON的\n。固定拓扑，不增删节点：左侧5阶段、方法4组、首带3柱、第二带4/5项、第三带5/4项、第四带3要素及2×3路径、末带3节点。缺失/多余字段或改变数量都会给出明确诊断。

表中宽度预算为保守全角字数。ASCII按半角，东亚模糊宽字符按全角，组合字符不重复计宽；仍须实际渲染复核。短字段不能因为槽位有空间就填无关文字。

## 调用

通过SKILL.md所示共享包装器调用scripts/innovation_chain_5stage.py，参数为内容JSON和-o输出drawio；--check只校验。共享资产只读，先复制example.json到当前工作区，输出写本次求解目录。生成后执行check_layout.py --strict及export_figure.py，再实际查看PNG/PDF。

## 尺寸与已知近似

参考裁剪画布1206×1743。示例最小字号18px；整幅缩到160mm宽时约6.8pt，不适合原样作为A4第一章路线图。247mm宽A3竖版约10.5pt，适合大型展示或可放大的电子浏览。用于A4必须另做科学上完整的精简布局并重新审核，不能直接缩字，也不能宣称当前版本已经适合正文。

使用SimSun宋体；原图水印及手机界面不重绘，原件完整保留。采样颜色按语义归并，标题渐变改为平涂；过长窄栏改成双字短行；细箭头端点外移1px，粗箭头头身比例为原生图元近似。矢量框、文本、箭头均可编辑，没有整图位图嵌入。完整对应表、三轮缺陷记录及像素差异见assets下本模板目录。

原图的文案、方法名称仅是演示来源，不作为模板默认推荐方法；源材料中的不规范术语须在实际题目适配时核对。
