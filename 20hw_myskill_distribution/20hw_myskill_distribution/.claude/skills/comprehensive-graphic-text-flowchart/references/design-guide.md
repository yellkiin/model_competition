# 逐问研究总览的设计与内容合同

正式合成前读取本说明、图库索引和项目结构图工作流。三种等级分开：来源、已核验结果、机制适用性、矩形整体及实际复核是必须项；浅马卡龙与常见面板组合是默认设计；宽箭头、导向标题、二维半为可选增强，不设配额。

## 内容与时序

先确认本问科学结果及独立核验，再合成和查看综合图，最后执行包含综合图的逐问完成审计。计划可保留预期结果与 pending；分析发现问题可返回求解。修改边框不要求重跑内容和依赖均未变化的昂贵计算。

从现有视觉计划读取本问全部图件候选及其科学问题、正式图/预览、结果来源、版本和状态。逐一选择或说明重复/不适用的具体理由，不另建结果目录。默认先直接嵌入已有合适原图或完整子图，其次裁空白/选子图/同源导出；只有解释缺口才补画机制或同源结果表达。一张有用结果也足够，不为面板数新增实验。纯解析无数值图可以具体说明例外；“为了简洁”“缩略细节不可读”不构成省略理由。

`overview_detail` 和结果面板 `detail_figure_id` 指向正文详细图。综合图允许直接缩小原图，坐标、图例、数字、表格单元格不要求逐项可读；不要求重排才能嵌入。自绘标题、主关系、关键概括与公式仍清晰。独立详细图原有质量门禁不降低。保留原图必要坐标、单位、范围和语义颜色，不能裁掉不利结果、改轴/平滑、非等比拉伸或将整页论文截图伪装成图件。

每问判断物理、系统、几何、状态/时序/拓扑、算法内部关系是否适用；实体设备不适用仍须考虑其他机制。适用时链接实际算法/物理结构子图并调用同端 skill，或以同一 skill 的真实图元直接绘制；登记 skill、来源定位与面板 ID。装饰图标、长段文字、“已考虑”不能代替解释。不适用须结合实际模型说明，允许纯解析表达，不硬塞设备或神经网络。

## 矩形布局

先确定实际物理尺寸、总体内容矩形、分区矩形、跨栏/跨行、安全内边距与连接通道。内容紧凑对齐形成规整矩形；允许无外描边、浅色底板间均匀窄白隙，虚线按需。不能把松散卡片套大框、用空板补齐轮廓，或借大底色掩盖内容稀疏。共享分隔只画一次，底色在内容后方。

可选布局：A 不等宽对象/方法/结果栏；B 顶部跨栏输入、中间真实并行、底部汇合；C 不等高二乘二与跨区；D 左侧跨行机制、右侧方法、底部证据；E 共享边缘的一体纵向带。按信息量分面积，不要求固定三栏、四格或每带都有结果。输入/约束/公式可单独成区，只要整图由实质机制与证据支撑。

通常一个核心机制和两至三个代表性结果、三至五个阶段可作为起点，不是验收阈值。内边距3–5mm、通道2–4mm、虚线0.6–0.9pt仅为设计建议，最终实际看图。机制与结果应有解释空间，不能用背景/图像文件面积伪量化科学内容。

## 主题与连接

唯一默认 token 见 [overview-theme.json](overview-theme.json)。白画布、高明度低饱和分区、深色导航字，原结果保留原有或白/透明底；不覆盖彩色蒙版、不改变数据系列颜色。通常取三至四色，不要求用满。自定义样式写工作区配置并纳入 dependencies，默认主题由共享 structure 资源依赖追踪。

主连接选统一形态家族，辅助关系按需要用相容细线：真实阶段流可用内嵌短文字宽箭头/流程带，标题可用导向旗标；真实汇合用括接/总线；比较、对应用无向线、共同标签或并排对齐。编号与位置足够时可无可见箭头，但计划保留关系。不要求辅线，不固定单一细红箭头，也不禁具有科学语义的红色。反馈、梯度、共享权重仍按真实含义区别，不能为美观制造因果。

箭中文字位于箭身安全矩形、不侵入尖部；不穿图例、公式或边框。宽带可从6–9mm试排，不是硬阈值。阶段标题约11–13pt、子标题9.5–11pt、关键说明8.5–10pt仅作用于新绘导航，不套用到直接缩略原图内部。避免重阴影、发光、装饰三维和多层套框。

## 实际 QA

沿用现有 QA 文件，在 `overview_review` 分别填写 `result_integration`、`mechanism_value`、`rectangular_composition`、`palette`、`navigation`、`non_text_graphics`、`thumbnail_detail_link` 的 status/observation。逐项 pending，实际打开整体、必要局部、PDF等尺寸页面、灰度后才能填 pass；需记录具体观察。拒绝装饰机制、松散框、空壳大背景和不可读导航，不能仅因缩略结果小字判失败。允许一张结果、纵向布局、窄白隙、无虚线或无宽箭头。

参考选型通常比较2–3张原图，十张无需每次全看。原图细字和红箭头是客观描述，当前继承组织而非历史数据、水印、原论文题注；新图采用本问结果，普通图保持 academic/modelviz 双来源规则。来源、版本、真实嵌入由记录与实际看图共同核对，机器不能证明美观或科学正确。
