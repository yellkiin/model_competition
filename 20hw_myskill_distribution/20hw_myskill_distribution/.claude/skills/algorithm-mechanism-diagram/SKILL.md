若嵌入真实输入图像、特征空间图或统计结果，按项目绘图规范第1.3–1.4节逐面板分类：真实图像/专业渲染走media，统计比较按双来源规则选用academic或modelviz并通过各自证据门禁，算法关系继续本skill。输入图和结果不能由参考图库或生成式增强替代。

先核对真实模型：模块顺序、tensor轴序及尺寸、参数来源、分支输入输出、concat与add（非拼接轴相等/逐元素尺寸相等）、共享参数的实际对象、loss计算和梯度路径、训练与推理差异。没有配置支持的层数/通道/权重不能由参考图补出。

## 后端选择

用于逐问综合图时，先取得父图ID、真实代码/配置定位、需要解释的内部操作和目标面板毫米尺寸。可复用详细结构图的必要局部或简化层级，保持张量变换、数据流、共享参数与梯度语义，不能以“建模/训练”文字框代替机制。保留可编辑源、矢量PDF、PNG和依赖供父图引用；透明/白底与浅色分区协调，自绘关键标签按显示尺寸复核。整图组织与已有结果的缩略展示许可读取综合图skill的references/design-guide.md。

同时评估参考匹配、复杂度、可编辑需求、公式排版、目标尺寸与实际渲染，记录理由；本机有draw.io也允许选TikZ。
- Python计算布局与投影坐标 → draw.io XML → CLI PDF/PNG：适合交互修改和2.5D薄片、长方体、多分支，draw.io直接绘图而非只拼排。
- Python + 本地PlotNeuralNet/TikZ → XeLaTeX：适合带状特征图与公式。先读 `assets/PlotNeuralNet-master/pycore/tikzeng.py`、所选 `layers/*.sty` 与相应示例TeX/PDF。复制依赖到输出工程并保留LICENSE；禁止修改上游。
- 直接TikZ：适合自由布局、复杂公式与局部解释，不要求复刻PlotNeuralNet所有默认样式。

可复用2.5D坐标及XML原语见 `scripts/projected_drawio.py`；PlotNeuralNet适配与已实测范围见 [后端说明](references/backends.md)。
