# 方法、约束与可证明的界

## 1. 题定优化对象

优化 `min T_q(P)`，其中 P=(操作划分、子图分核、各核子图顺序)，q=1/2/3。只允许两个输出字段。原图、操作代价、张量大小、官方容量/带宽、FIFO、Step1/2/3 和输入/输出 COPY 全部保持原样。

同一框架的三种执行语义必须区分：Q1 是子图=Task，跨子图都经 DDR，核内前 Task 完成后还有 100 周期等待，跨核前驱 1000；Q2/Q3 是每核一个 Task，跨核 COPY 等待 500；Q3 读发射查询 FIFO、完成时填充、命中不刷新，DDR 60 与 Cache 250 字节/周期独立。Q2/Q3 不能在评分中强加“整个前子图全部完成才可启动后子图”的虚构屏障。

已经读取原题 DOCX 提取全文、附件 README、官方核内/多核说明与原函数。以原题规定的正式二部图为对象。代码兼容的额外边型不构成题目扩展要求。

## 2. 结构构造与合法性范围

### 2.1 分支链与廉价汇合区

仅对单出单入相连的节点收缩成链，避免拆断大数据中间结果。之后在链商图上，用 0.25×场景跨核等待为廉价阈值；定义标签 h(v)=max_{u→v}(h(u)+1{u 非廉价})。只合并同标签廉价诱导图的弱连通分量，且其总计算量不超过两倍等待。

证明要点：链内部没有可绕开的支路；廉价连通区不能经非廉价节点离开再返回同标签，因为离开该节点会严格增大标签。经同标签廉价节点的路径本来就在同一诱导连通分量中。由此这些收缩保持商图无环。

在链商图上做关键路径优先与多 Pipe 日历分核；相同商图深度的组彼此无依赖，可按核心合并。这暴露大连通图的内部并行分支，不假定“一个 WCC=一个不可分任务”。

### 2.2 非均匀阶段 DP

将单调深度轴压为最多 16 个不可拆层区间。每个候选连续区间内求 WCC 并估计分核 Pipe 工作、Tensor 集合读写及串行驻留峰值。DP：D(j)=min_{i<j}[D(i)+C(i,j)]。

它是**固定区间轴上加性代理的精确最短路**，不是官方问题的精确解。C 包含 max(计算估计, 搬运估计)、驻留超额惩罚与等待项；实际阶段可能交错执行，真实 Step2/3 峰值也不等于该串行代理。不能将 D 作为全局下界或声称有限 DP 找到原问题最优。

### 2.3 共享输入下的阶段驻留流水线

对互无计算依赖的全局 WCC，将单调深度区间映射到不同核心组，WCC 作为微批次在阶段间流动；阶段内允许以更细子图优先级聚合同层读取。在原图上没有新增算子、复制计算或修改依赖。不同阶段的核心集合不相交；原始跨阶段依赖只向前，同阶段不同微批 WCC 无依赖，因此商图与核心顺序结构相容。

Q1 还构造少活跃核心的候选，减少同一输入的 Task 级重复读取。允许空核心列表不等于修改模拟核数。细阶段在 Q1 可能更差，不能照搬 Q2/Q3 的收益。

`frontier_cuts` 另解一个明确受限子问题：给定阶段数、单调轴和分阶段工作量上限，DP 最小化切点 Tensor 前沿字节。返回的是第一次可行工作松弛下的受限最优；既不是完整调度最优，也不保证官方周期更好。开发实验已经观察到前沿更好的候选未必胜出，故不把它当成主目标。

### 2.4 官方验证与单调改进

上述结论只保证部分结构约束。官方添加 Pipe FIFO、COPY、Spill、内存复用边后仍可能出错。所有正式 incumbent 都必须成功经过原函数的完整评估。保存合法 incumbent 后才能继续构造/评估；非法或较差候选不得覆盖它。

因此同一次固定输入/配置运行内，U_(t+1)≤U_t；最终 U 不劣于已通过评估的 fast 初解。该保证不涵盖尚未输入/重新验证的旧方法方案，不是跨版本或跨种子的普遍不退化保证。

## 3. 三问统一的上下界证书

只取评估构图确实保留的非 COPY 直接计算依赖。正式图只包含 Tensor↔Op，计算服务时间取官方实现的 max(1,cycles)。令 L_comp 为这些依赖上的最长计算路径，W_p 为 Pipe p 的总计算服务量，n 为题定核数。

LB=max(L_comp, max_p W_p/n) ≤ T_q^*。

证明：放松全部通信、容量与额外顺序只能缩短完成时间；任一依赖链必须顺序完成，而每种 Pipe 最多有 n 个并行服务实例。程序的 COPY 收缩关系可用于合法拓扑，但没有把未经确认保留的收缩路径用来加强 LB。

对于经过原评估通过的方案 P，U=T_q(P) ≥ T_q^*，故：

- LB ≤ T_q^* ≤ U；
- 当 LB>0，U/T_q^* ≤ U/LB；
- 最优加速比 S_q^*=T_original/T_q^* ≤ T_original/LB。

这是真实实例级的性能比上界，不是与输入无关的常数近似保证。只有完整同一案例集合时才能对最后一个上界取平均约束平均加速比。上界高于 4.5 不证明可达到 4.5；分母为零、无单核或 bound_violation 时不输出认证比。

对固定候选 P，Q2/Q3 还可在保留依赖上累加每次跨核 500 周期，并结合已分核的最大 Pipe 工作；Q1 在 Task 依赖与同核顺序上累加所需等待和每 Task 最大 Pipe 工作。得到 LB(P)≤T_q(P)。当 LB(P)>当前有效 U 时可跳过该候选；它**不能替代全局 LB**。

没有对驻留/FIFO 代理宣称下界，没有用预计 Cache 命中去做“认证”剪枝，没有实现完整原问题 MILP、Benders 对偶或神经代价模型。

## 4. 复杂度与工程成本

链/依赖扫描是线性的，优先队列分核另有排序和核心数因子；DP 至多 136 个区间，每个区间扫描受影响节点/Tensor。当前实现仍有反复扫描，不把它写成严格 O(V+E) 的完整求解器。DP 默认只在有限规模/候选路径使用；其他路线也可能遇到大型官方评估较慢。

原函数常驻子进程只减少主机求解成本，不改变模拟器周期。计算与完成时间单位分开；所有构造、验证、超时和 I/O 计入求解墙钟，记录原函数耗时的子项。最后还要用 Windows 和新图检验，而不是用 Linux 秒数替换 Windows 性能。
