# 理论口径：可行上界、条件性松弛下界、启发式代理

统一问题为 min_{P in F_q(G,n)} T_q(P)，P 为操作分组、子图分核和每核顺序。F_q 包含该问完整官方执行链的约束。三问共用求解骨架，但不共用同一个 Task/通信/缓存模型。

## 真实可行上界

只要原评估器成功得到正有限 Makespan，且没有改动题定配置，该方案 P 的 U=T_q(P) 就是最优目标值 T_q* 的可行上界。仅接受更小的 (Makespan, 新增搬运量) 使已验证 incumbent 单调不劣。这不保证第一次构造必然可行，也不保证全局最优。未取得成功评估时没有可行上界。

## 计算松弛下界（明确条件）

取每个非 COPY 操作输入中非负 cycles，忽略 COPY、等待、Spill 与容量。每核每种 Pipe 只有一个服务槽；如果这些计算操作在官方构图中保留，服务时间不少于上述 cycles，并保留原始直接计算边及同一 Tensor 直接生产者到消费者的依赖，则

LB0 = max(最长保留计算路径, max_pipe 总计算工作量(pipe)/核数) <= T_q* <= U。

实现不把为拓扑排序收缩 COPY 得到的路径当作证明边，也不使用 upstream Graph.cost 的 max(1, cycles) 地板作下界。本条件须对实际官方版本确认，程序因此输出 conditional_compute_relaxation_see_THEORY 而不是“已认证最优性缺口”。条件满足且 LB0>0 时 U/LB0 是该实例的性能比上界；不是输入无关的常数近似比。若发现 LB0>U，应记录 bound_violation 并检查条件，不截断下界掩盖矛盾。

## 方案相关通信下界与实现边界

对 Q2/Q3 固定方案，在确实保留的依赖上给跨核边加固定等待 delta，可得 L_P(v)=cycles(v)+max_u[L_P(u)+delta I(core(u)!=core(v))]。这至多是 T_q(P) 的下界，不是 T_q* 的共同下界。当前 proxy 还加入 Pipe 日历、块间 gate、COPY 估计、驻留风险与 FIFO 推测；这些额外项不是非低估量，所以 proxy.score 和 communication_calendar_proxy 都不能用来作严格剪枝。

Q1 需要在 Task 图考虑边界及同核相邻 Task 等待，不能照抄 Q2 的逐操作 delta 公式。驻留函数只是序列生命周期代理，不是实际并行 L1/UB 峰值。FIFO 函数只是估计访问时刻下的发射查询/完成填充，没有完整带宽竞争与生成的 Spill 请求；真实命中率只能取 Q3 官方输出。

## 结构合法性与完整可行性

深度 d(v) 对每条收缩依赖边 u->v 严格增加。按深度形成有序带；带内按弱连通块划分后，不同块之间没有边。将同带同核的块聚合，带内仍无相互依赖，跨带只向前。按带执行，因此商图和附加同核顺序无环。

邻域只迁移整个块，并保持同一全局拓扑排列；只合并全局相邻且同核的两个块。这保持商图顺序，但不证明官方最终加入的 Pipe FIFO、跨核 COPY、Spill、地址复用依赖仍无环；必须调用原评估链。不能把结构证明写成三问完整执行可行性定理。

## 尚未实现／尚未验证

本版不是松弛变量舍入的完整 MILP/LP，也没有对偶优化、完整增量更新或通用常数近似保证。规模选择和权重是固定候选规则，须用真实小实验检验。不存在本 PR 已完成的官方性能结果，不存在已证明超过旧论文的结论。
