## 4. 中继与分区

12箱种子7的八条运输路线配两次中继，联合返回719.03秒，中继能量0.345812kWh。10秒及所有阶段边界检查共512点，零断联，最小链路裕量0.393426dB。两套运输候选的coopt比较也已执行，选择工期719.03秒、运输与中继总能耗5.847152kWh的方案。

严格固定共享中继任务的分区形成一个连通分量，无法两分。复制保障任务的解释下：两组额外需1架中继+1组能源，三组额外需2架+2组；两种都是固定支持关系上的枚举结果，未改动时刻。不同解释不能混成同一最少资源结论。

对称双点瓶颈实例另存 `configs/d_radio_bottleneck.json` 和 `results/d_radio_bottleneck_transport.json`：

```bash
python -m research_fd.d_experiments radio \
 --input research_fd/configs/d_radio_bottleneck.json \
 --plan research_fd/results/d_radio_bottleneck_transport.json \
 --out research_fd/outputs/bottleneck_fixed \
 --mode fixed --grid 1 --sample-step 60 --max-sessions 2500 --seconds 2

python -m research_fd.d_experiments radio \
 --input research_fd/configs/d_radio_bottleneck.json \
 --plan research_fd/results/d_radio_bottleneck_transport.json \
 --out research_fd/outputs/bottleneck_repair \
 --mode retime --grid 1 --sample-step 60 --max-sessions 6000 \
 --shift-window 2100 --horizon 3600 --seconds 10
```

固定模式不可行；900秒窗口的有限模型也不可行；2100秒窗口可行。保存的修复来自每阶段4秒运行：两个启动时刻2100/480秒，中继两次出返仓，联合返回2813.33秒，118个10秒加密点无断联。工期阶段超时，所以只声称修复可行，延长预算有可能改善。求解器时限、版本和机器差异会影响可行解具体时刻。
