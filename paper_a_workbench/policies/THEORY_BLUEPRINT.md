# 统一模型与理论写作蓝图

这是准备阶段的科学组织方案。采用的算法版本由 SOURCE_LOCK 和 PUBLICATION 唯一确定；正文写作前按理论核对角色逐条核实实现对应关系。本文件没有预填最终实验数值。

## 一条主线

在固定资源与评价规则下，联合选择无环子图划分、核心分配和核内子图顺序，并在给定求解时间内不断改进已验证的可行方案。结构划分、驻留优化和 FIFO 复用是同一决策空间中的不同邻域，评价目标始终相同。三个问题改变的是执行任务和存储资源的语义，不需要写成三套互不相关的数学模型。

## 统一定义

沿用题面的操作—张量有向无环图。令 O_c 为需分配的核内操作集合；P={S_1,…,S_m} 为 O_c 的非空、不交、完备划分，μ(S_i) 为其核心，σ_k 为核心 k 上子图的全序。方案记为 π=(P,μ,{σ_k})。每个子图恰好出现于一个核内序列；跨子图依赖与各核顺序共同满足无环性。完整执行可行性由题定构建、核内排程与多核模拟规则定义，记可行集合为 F_q。

对问题 q 的扩展操作集合 Õ_q(π)，结束时刻为 f_o(π)，定义

T_q(π)=max_{o∈Õ_q(π)} f_o(π)，
B_q(π)=B_q^scheduled(π)−B^original。

首先最小化 T_q，在周期相同时以 B_q 作为择优准则。这是本方法的字典序规则，题面规定 Makespan 为主指标、额外搬运为次指标。最终版本若调整同分准则，应更新方法段而非修改题面解释。

## 三问差异的统一表达

问题一：一个子图构成一个 Task，跨 Task 数据经 DDR，激活时刻受同核顺序和跨核前驱等待约束。

问题二：同核全部子图合为一个 Task，驻留与换入换出由固定核内规则决定；跨核传输具有固定同步延迟。按生产者/消费者的 Task 或核心集合核算张量流量，避免逐操作边重复计费。

问题三：沿用问题二，COPY_IN 发射时查只读共享缓存、完成时按官方事件过程处理填充，命中不刷新 FIFO。以（周期，事件序号）的字典序作为事件时标，定义每次读取的发射位置 s、可用填充位置 f、相应驻留段结束位置 e；s∈[f,e) 描述该次观测驻留窗口，同周期依原事件顺序判定。同一张量可以有多个驻留段，顺序变化后这些时刻需要重新评价。共享 DDR 与缓存读池分别结算，命中字节率不作为 Makespan 的替代目标。

## 两个可直接核对的性质

**性质一（保留解的单调性）。** 对已经取得可行方案的时间 t，设 C(t) 为在 t 前完成官方评价并通过检查的候选集合，U(t)=min_{π∈C(t)}T_q(π)。若只增加完成评价的候选而保留原可行解，则 t₂≥t₁ 时 C(t₁)⊆C(t₂)，因此 U(t₂)≤U(t₁)。证明只用集合包含和最小值定义。它对应同一条运行轨迹；求解起点和冷/续优化计时定义在实验协议中明确。

**性质二（已知下界的差距估计）。** 设 L_q≤T_q*≤U，L_q 是对整个 F_q 有效的下界。由 U−T_q*≤U−L_q 得 (U−T_q*)/U≤(U−L_q)/U。论文中先证明采用的每一个下界为何对整个可行集合有效，再使用这一估计。针对某一个固定划分或顺序的下界登记为条件下界，只用于相应候选。

计算依赖路径和每类计算流水线的总工作量给出常见松弛：忽略非负等待与传输后，最长计算依赖路径仍不得缩短；n 个同类计算流水线完成总工作 W_p 至少需要 W_p/n。访问流量下界要按三问实际必要访问集合分别推导，不能把问题二的所有 DDR 读直接用于问题三。

## 方法组织

合法初解 → 多尺度/结构邻域 → 驻留和搬运邻域 → 复用顺序邻域 → 统一候选评价与保留解更新。候选生成、选择和资源上限属于搜索实现；不能把其模块数量本身写成贡献。复杂度写为图规模、生成的候选数和实际评价成本的函数；局部 DP 的状态范围、代理目标和搜索窗口单独定义。
