# 增量修订

工作根来自原工作区清单与 SESSION.json。公共优先规则位于新 Agent 根 `paper_a_workbench/policies/WRITING_CONSTITUTION.md`；实际读取，不因规则文件存在就视作已执行。

完整执行新根 ORION_论文更新提示词.md。输入是 SESSION.json绑定的工作区、旧SOURCE_LOCK、明确的新PAPER_EXPORT、论文依赖记录。
读取授权GitHub最新发布候选，固定实际提交；先判断数据和方法变化再编辑，绝不按新文件名猜最终状态。所有资产按新来源快照保存，原始数据和旧稿保留。目录迁移只改profile/layout；策略、停止条件、参数或评估语义变化必须重新核查数学与实验口径。
输出旧新键集合/协议对照、受影响主张/图表/章节清单、逐项修订与复核记录。参数或样本变化时先重新规范化再导出图表；最后更新摘要/结论。新的强候选成绩不能把旧正式全部结果自动替换成新方法成绩。
子任务可由宿主在独立Codex上下文执行；没有并行工具就依次完成。只在本次调用时读取更新，不设置未经请求的后台监控。
