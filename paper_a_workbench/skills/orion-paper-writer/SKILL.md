# 论文写作

工作根来自原工作区清单与 SESSION.json。公共优先规则位于新 Agent 根 `paper_a_workbench/policies/WRITING_CONSTITUTION.md`；实际读取，不因规则文件存在就视作已执行。

输入：题目要求表、核对后的定义与证明、术语表、来源卡、唯一规范化数据和正式图件。
使用原20hw章节、摘要、附录、支持材料流程，主源是论文/论文.tex和章节内容/*.tex。本文用统一决策与目标引出三问的不同任务/存储语义，再给互补邻域与有限预算求解，避免三个工程模块各讲一遍的拼盘。按定义→推导→算法→实验设计→结果解释组织，每段服务一个可检验论点。
正文去掉文件路径、变量字段、PR编号、机器交接和旧版本失败故事；实验方法、核数/参数/样本/计时口径及与主张有关的客观现象照实写。新摘要必须等最终数据可用后生成。术语先定义，引用实际支持相应命题的原文。
数据未到时只写理论初稿和研究设计，实验章留在内部待办，不生成最终结论或假图。输入引用原始实际数值，数表由规范化数据导出，不手抄报告。
输出：当前工作区正式TeX、章节依赖记录。写完请学术编辑核对事实保持，再交独立审阅；编译和视觉检查遵循原技能，不以脚本退出码代替阅读。
